06 - Full example
=================
Verdant Grove: everything together in one mod.

  mod.json     A druid-circle theme (from Ashen Crown) with page, wheel and card colours, a CSS file, two sounds
               that only play in this theme, and a pack with a new race and a new companion.
  theme.css    Extra styling for the theme.
  knock.wav    The wheel's tick sound, for this theme only.
  chime.wav    The sound when the wheel stops, for this theme only.

This is the same example that ships with the game's source (mods/example-mod). Pick it apart, or use it as the
starting point for a big mod.
