00 - Blank
==========
The smallest useful mod: one theme that starts from Ashen Crown and changes the accent colour.

1. Rename this folder (for example "my-first-mod").
2. In mod.json change "id" (lowercase letters, numbers and dashes), "name", "author" and "description".
3. Change "base" to the look you want to start from: ashen, astral, iron or bloodmoon.
4. Add more "vars" (see reference/theme-variables.md), or copy parts from the other templates.

A mod must contain at least one theme, sound or pack, so keep the theme or replace it with something else.
