# Brand

Transparent logos for store pages, banners, videos and mod themes. One per theme, trimmed to the artwork:

| File | Theme |
| --- | --- |
| `logo-ashen.png` | Ashen Crown (the main logo) |
| `logo-astral.png` | Astral Oracle |
| `logo-iron.png` | Iron Litany |
| `logo-bloodmoon.png` | Blood Moon |

They are made from the painted logos in `app/art/` by `python scripts/make-transparent-logos.py` (needs Pillow and
numpy). They look best over dark or mid-tone backgrounds; over white the glow fades to a soft edge.

The logos were generated with Grok Imagine (xAI). Created with Grok. Keep that phrase wherever they are published;
see [docs/art-credits.md](../docs/art-credits.md).
